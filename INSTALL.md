# deflacue installation

Python `pip` package is required to install `deflacue`.

## From sources

Use the following command line to install `deflacue` from sources directory (containing `pyproject.toml`):

```shell
pip install .
```

## From PyPI

Alternatively you can install `deflacue` from PyPI:

```shell
pip install deflacue
```

Use `-U` flag for upgrade:

```shell
pip install -U deflacue
```
